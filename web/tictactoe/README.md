# Tic Tac Toe Web Game

A browser-based Tic Tac Toe game with an unbeatable minimax AI opponent.

## Running Tests

To run the test suite:

```bash
npm test
```

This will run all tests in the `src/` directory using Node's built-in test runner.

## Serving the Game

To serve the game locally:

```bash
npm run serve
```

This will start an HTTP server on port 8000. Open your browser and navigate to `http://localhost:8000` to play the game.

## Project Structure

- `src/` - Source code including game logic, AI opponent, and tests
- `index.html` - Main HTML entry point for the game

## Development

This is a Node.js ESM module project. All JavaScript modules use ES module syntax (`import`/`export`).
